# 📦 Sistema de Estoque Inteligente

Projeto acadêmico desenvolvido durante o curso de Ciência da Computação na Universidade São Judas Tadeu.

## 📌 Sobre o projeto

O Sistema de Estoque Inteligente tem como objetivo facilitar o controle e gerenciamento de produtos em estoque, permitindo acompanhar quantidades, movimentações e identificar produtos com estoque baixo.

O projeto está sendo desenvolvido em equipe, passando pelas etapas de planejamento, levantamento de requisitos, modelagem, prototipação e desenvolvimento.

## 🚀 Funcionalidades planejadas

- Cadastro de produtos
- Consulta de produtos em estoque
- Atualização de quantidades
- Controle de entrada e saída de produtos
- Alerta de estoque baixo
- Visualização das informações de estoque
