## Requisitos do Sistema

Os requisitos do Stock IA foram definidos com base nas necessidades de pequenos e médios comércios para controle, acompanhamento e análise de estoque.

### Requisitos Funcionais (RF)

**RF001 – Cadastrar Produto**

O sistema deve permitir o cadastro de produtos, contendo informações como nome, categoria, quantidade, preço e estoque mínimo.

**RF002 – Editar Produto**

O sistema deve permitir a alteração das informações de produtos cadastrados.

**RF003 – Excluir Produto**

O sistema deve permitir a exclusão de produtos cadastrados.

**RF004 – Registrar Entrada**

O sistema deve permitir registrar a entrada de produtos no estoque.

**RF005 – Registrar Saída**

O sistema deve permitir registrar a saída de produtos do estoque.

**RF006 – Consultar Estoque**

O sistema deve permitir consultar os produtos e suas respectivas quantidades disponíveis.

**RF007 – Definir Estoque Mínimo**

O sistema deve permitir definir uma quantidade mínima de estoque para cada produto.

**RF008 – Emitir Alerta de Estoque Baixo**

O sistema deve gerar um alerta quando a quantidade de um produto atingir ou ficar abaixo do estoque mínimo definido.

**RF009 – Consultar Histórico**

O sistema deve permitir consultar o histórico de entradas e saídas dos produtos.

**RF010 – Exibir Dashboard**

O sistema deve apresentar um dashboard com indicadores e gráficos relacionados ao estoque.

**RF011 – Analisar Movimentação**

O sistema deve identificar produtos com maior e menor movimentação com base nos registros armazenados.

**RF012 – Prever Reposição**

O sistema deve analisar o histórico de movimentações para estimar quando determinado produto poderá precisar de reposição.

**RF013 – Gerar Recomendações**

O sistema deve fornecer recomendações relacionadas ao estoque com auxílio de análise de dados e Inteligência Artificial.

**RF014 – Autenticar Usuário**

O sistema deve permitir autenticação de usuários para acesso às funcionalidades disponíveis.

### Requisitos Não Funcionais (RNF)

**RNF001 – Usabilidade**

O sistema deve possuir uma interface simples, intuitiva e de fácil utilização.

**RNF002 – Desempenho**

O sistema deve executar as principais operações de consulta e movimentação de estoque em até 3 segundos, em condições normais de utilização.

**RNF003 – Segurança**

O sistema deve proteger o acesso às informações por meio de autenticação de usuários.

**RNF004 – Responsividade**

O sistema deve possuir interface responsiva, adaptando-se a computadores, tablets e smartphones.

**RNF005 – Disponibilidade**

O sistema deve ser acessível pela internet por meio de navegadores compatíveis, desde que haja conexão e os serviços necessários estejam disponíveis.

**RNF006 – Integridade dos Dados**

O sistema deve manter a consistência das informações armazenadas, evitando alterações indevidas nos dados de estoque.

**RNF007 – Compatibilidade**

O sistema deve funcionar nos principais navegadores modernos.

**RNF008 – Manutenibilidade**

O sistema deve ser desenvolvido de forma organizada, permitindo futuras correções e implementação de novas funcionalidades.

**RNF009 – Persistência dos Dados**

O sistema deve armazenar os dados de produtos, usuários e movimentações de forma persistente, garantindo que as informações permaneçam disponíveis após o encerramento de uma sessão.
